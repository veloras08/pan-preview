# 资源分享盘 移动端视觉 v7

可缩放、带批注的画布：打开 `index.html`（拖动平移、滚轮或双指缩放、点击单屏放大、← → 切换）。

仓库目录：https://github.com/veloras08/pan-product/tree/main/design （仓库成员可见）

- `index.html`：画布查看页，按设计稿原布局排列 32 屏和批注
- `screens/`：32 个画板的 PNG（390×844，@2x）
- `source/`：画板源文件（`.dc.html`）和画布索引 `canvas.json`

主色 #3A6DF2。按画布上的行顺序排列：四个 Tab 根页面与传输、搜索 → 文件子页与弹层 → 空间（关注者）→ 空间（创建者）与创建空间 → 预览与「我的」子页 → 传输操作与确认弹窗。
